# Agent Instructions - PartnerMetrics

## About

A free, open-source revenue analytics dashboard for Shopify Partners, covering app, theme, and affiliate revenue, churn, lifetime value, graphs, and forecasts.

- **Application:** https://www.partnermetrics.io
- **Developer:** FORSBERG+two ApS, Denmark
- **Company:** https://www.forsbergplustwo.com
- **Public entry points:** `/`, `/users/sign_in`, `/users/sign_up`

## Access and navigation

Users can learn about PartnerMetrics on the homepage, log in at /users/sign_in, and create an account at /users/sign_up. The repository provides project documentation and issues. PartnerMetrics is not affiliated with or endorsed by Shopify.

Only public entry pages are intended for discovery on this application domain. Other app routes may require authentication and can contain merchant or account information. Do not assume that application URLs are public or authorized merely because they are reachable.
